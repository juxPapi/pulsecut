## Name status — PulseCut

- Chosen name: **PulseCut** (close variant of CutPulse, adopted 2026-11-19 after
  the user declined to keep CutPulse).
- Trademark screen (performed 2026-11-19) for the **CutPulse** candidate:
  - Official USPTO trademark search (Wordmark / Combined-mark field-tag queries):
    **0 results** for `CUTPULSE` and for the `CUT PULSE` phrase — no identical
    U.S. registration found.
  - TMview (≈70 participating offices incl. EUIPO, WIPO, UK, USPTO, IN): no rows for
    `cutpulse`; unrelated hits only (e.g. `EXECUTIVE PULSE`).
- Commercial finding: `cutpulse.com` is **registered** (BigRock, registered
  2026-02-24, expires 2027-02-24) and currently hosts a live "CutPulse — AI Video
  Studio" (Seedance 2.0). `cutpulse.io/.app/.co/.ai/.tv` were available. The live
  use + domain made the CutPulse name impractical → the user chose the close
  variant **PulseCut**.
- Domain status: `pulsecut.com` **registered**; `pulsecut.io/.app/.co/.ai/.tv`
  **available**.
- Web footprint for the final name: no PulseCut-specific software app found in
  app-store / npm searches during screening.
- Caveat: this screening is preliminary and not legal advice; a formal clearance
  search before filing remains advisable.
